The Motherboard

The motherboard is like a template. It holds all ports and sockets, ready for other components to be connected. The motherboard also has its own chipset, which controls communication between the CPU, RAM, secondary storage and peripherals. It is the body of a computer!

Below is an image of a relatively modern motherboard.

The CPU (Central Processing Unit)

The Central Processing Unit or CPU is the brain of the computer. It handles instructions at billions of times a second. CPUs have multiple cores, which are small copies of a CPU which can be used at the same time if a program supports multicore usage!

Click here for a fact.

CPUs have multiple sockets for installation depending on the motherboard, such as AM4, AM5 and LGA 1700.

The GPU (Graphical Processing Unit)

The GPU is a rectangular, card-like component which slots into a motherboard's PCIe slot. It is used to render 3D scenes, whether it is in video games or other rendering applications (such as Blender). The main producers of today's GPUs are NVIDIA, AMD and even Intel. AMD also create CPUs but Intel create CPUs, GPUs, chipsets and even NICs, which I will go into detail further down this webpage.

Below is an image of a modern day NVIDIA GeForce RTX 5080 manufactured by ASUS.

The RAM (Random Access Memory)

RAM is what is known as primary storage. It holds data and instructions for the CPU and the reason it is known as primary storage is because this is where the CPU goes first. It is also volatile (Click the button below for context!).

Click here for context. What is the difference between volatile and non-volatile storage? Volatile storage is when the devices will lose its data when it loses its power. If the device is non-volatile, it retains its data while power is off. As stated, RAM is volatile.

Below is an image of a desktop RAM kit.

Click here for a fact. The CPU has small yet incredibly fast onboard memory known as cache. If an instruction or piece of data is used frequently, it is cached (placed in the cache, although that may have been obvious) so that less distance is travelled to fetch instructions, resulting in less system latency.

Secondary Storage (This is a longer section)

Secondary storage is used to store semi-permanent data. It holds the Operating system (for example, Windows 11) and program files to be loaded into RAM. Secondary storage has many formats. The main three are magnetic, optical and solid state.

Magnetic storage

Magnetic storage, such as the Hard Disk Drive, stores 1s and 0s on the internal disk. The HDD uses a read/write head to recognise information from the disk. HDDs often have large storage capacities but are very slow due to their mechanical infrastructure and can fail over time or if dropped.

Below is an image of a modern Hard Disk Drive. The Seagate SkyHawk!

Optical storage

Optical storage is an external disc which has pits and lands which store 1s and 0s. An external reader is required for these discs (optical discs) to be read or written to. Optical storage has multiple formats. CD, DVD and Blu-Ray, all with extensions of R (Recordable: once written to, the data is permanent.), RW (Rewriteable: can be rewritten to, similar to a reversible chemical process.) and ROM (Read only. Cannot be written to). Optical storage is very portable and also the cheapest per GB (Gigabyte) but can be damaged easily through scratches.

Below is an image of a Vertabim DVD-R optical unit.

Solid-state storage

Solid-state storage is a non-mechanical storage option which uses flash memory. It is non-volatile (defined in the RAM section) and is the fastest of all three as it has no moving parts and can read and write at thousands of MB/s (Megabyte) per second!

NIC (Network Interface Controller)

NICs connect a device to a network. They have a MAC address and an IP address so that data can be routed to said computer. Most modern motherboards have them integrated and can connect wired or wirelessly. MAC addresses are permanent addresses which are used to connect devices to a wired network (the cables used are called ethernet cables). IP addresses are assigned via DHCP by a wireless network (can also be adjusted by a user) and are used to connect a device to a wireless network.

Click here for a fact. When IPv4 was first introduced, the demand was so high that we eventually ran out of IPv4 addresses! It was later placed alongside a modern successor called IPv6, which has a virtually infinite number of addresses.
